Тема 01

Переменные — место для хранения данных

Переменная — это имя, под которым программа хранит какое-либо значение. Можно представить её как подписанную коробку: у коробки есть имя, а внутри лежит число, текст или результат вычисления.

Пример
name = "Маша"
age = 12
height = 145.5

Здесь созданы три переменные:

  • name хранит строку "Маша";
  • age хранит целое число 12;
  • height хранит дробное число 145.5.

Как работает знак равенства?

В Python один знак = означает присваивание: вычислить значение справа и сохранить его в переменную слева.

score = 5
score = score + 3
print(score)  # 8

Во второй строке Python берёт старое значение score, прибавляет 3 и сохраняет новое значение. Поэтому после выполнения переменная равна 8.

Важно: = — присваивание, а == — сравнение. Это разные операции.

Правила имени переменной

  • Имя может содержать английские буквы, цифры и символ подчёркивания _.
  • Нельзя начинать имя с цифры: 2name — ошибка.
  • В имени нельзя использовать пробел: вместо my age напиши my_age.
  • Большие и маленькие буквы различаются: age и Age — разные имена.

Пример из задачи

Нужно сохранить количество яблок и вывести его.

apples = 7
print(apples)
Результат: 7
Тема 02

Команда print() — вывод информации

print() показывает на экране то, что находится внутри круглых скобок. С её помощью выводят текст, числа, значения переменных и результаты вычислений.

1. Вывод текста

print("Привет!")
print('Я изучаю Python')

Текст необходимо заключать в кавычки — одинарные или двойные. Главное — открывать и закрывать строку одинаковыми кавычками.

2. Вывод чисел и вычислений

print(10)
print(4 + 6)
print(20 - 3)
10
10
17

3. Вывод переменной

city = "Орёл"
print(city)

Если написать имя переменной без кавычек, Python выведет её значение. А вот print("city") выведет само слово city.

4. Несколько значений в одном print()

name = "Аня"
age = 11
print("Меня зовут", name, "мне", age, "лет")
Меня зовут Аня мне 11 лет

Запятые позволяют передать в print() несколько значений. По умолчанию между ними ставится пробел.

Тема 03

Типы данных и функции str(), int()

В Python у каждого значения есть тип. На этом этапе особенно важно различать строку и число.

int — целое число

Например: 7, 0, -12. С числами можно выполнять математические действия.

str — строка

Текст или последовательность символов в кавычках: "7", "Привет".

Обрати внимание: 7 и "7" выглядят похоже, но имеют разные типы. Первое — число, второе — текст.

Функция int()

int() преобразует значение в целое число, если это возможно.

number = int("25")
print(number + 5)
30

Строка "25" превратилась в число 25, поэтому Python смог прибавить 5.

Важно: int("привет") вызовет ошибку: слово нельзя превратить в целое число. Также int("4.7") не сработает, потому что строка содержит точку.

Функция str()

str() преобразует значение в строку. Это полезно, когда нужно соединить текст и число.

age = 12
message = "Мне " + str(age) + " лет"
print(message)
Мне 12 лет

Без str(age) нельзя напрямую соединить строку и целое число с помощью +.

Сравним на примере

a = "10"
b = int(a)
c = str(10)
print(a, b, c)

На экране будут похожие символы 10 10 10, но типы переменных разные: a — строка, b — число, c — строка.

Тема 04

Команда input() — ввод данных

input() позволяет программе получить данные от пользователя. Когда Python доходит до этой команды, программа ждёт, пока пользователь что-нибудь введёт и нажмёт Enter.

name = input("Как тебя зовут? ")
print("Привет,", name)

Текст внутри скобок — подсказка, которую увидит пользователь. Введённое значение сохраняется в переменную name.

Очень важное правило: input() возвращает строку

Даже если пользователь ввёл цифры, Python сначала воспринимает их как текст. Если нужно выполнять математические действия, используй int().

age = input("Сколько тебе лет? ")
age = int(age)
print(age + 1)

Можно записать короче — сразу преобразовать результат ввода:

age = int(input("Сколько тебе лет? "))
print(age + 1)
Запомни: input() — получить данные; int(input()) — получить данные и превратить их в целое число.

Тема 05

Работа со строками: upper(), lower(), len()

Строка — это текст, состоящий из символов. Например: "Python", "Привет, мир!", "12345".

Метод upper() — заглавные буквы

Метод upper() возвращает новую строку, в которой все буквы переведены в верхний регистр.

word = "Привет"
print(word.upper())
ПРИВЕТ

Метод lower() — строчные буквы

Метод lower() возвращает строку, в которой все буквы переведены в нижний регистр.

word = "ПРИВЕТ"
print(word.lower())
привет

Эти методы часто нужны, чтобы сравнивать слова независимо от того, какими буквами их ввели.

answer = input("Напиши да: ")
if answer.lower() == "да":
    print("Верно!")

Функция len() — длина строки

len() считает количество символов в строке. Учитываются буквы, цифры, пробелы и знаки препинания.

word = "Python"
print(len(word))
6
text = "Привет, мир!"
print(len(text))
12
Не перепутай: upper() и lower() записываются через точку после строки или переменной. А len() — отдельная функция, поэтому строка помещается внутрь скобок: len(word).

Тема 06

Составные логические условия внутри переменных

Логическое выражение — это проверка, результатом которой становится одно из двух значений: True (истина) или False (ложь).

Например, выражение age >= 18 проверяет, больше ли возраст или равен 18.

age = 20
is_adult = age >= 18
print(is_adult)
True

Переменная is_adult хранит не число и не текст, а результат проверки — логическое значение.

Оператор and — И

and объединяет несколько условий. Всё выражение будет истинным, только если каждое условие истинно.

Пример

temperature = 22
sunny = True
good_weather = temperature >= 20 and sunny == True
print(good_weather)
True

Проверяются два условия: температура не меньше 20 И sunny равно True. Оба условия верны, поэтому результат — True.

Оператор or — ИЛИ

or объединяет условия так, что всё выражение истинно, если хотя бы одно условие истинно. Ложным оно будет только тогда, когда ложны все условия.

Пример

has_ticket = False
has_invitation = True
can_enter = has_ticket == True or has_invitation == True
print(can_enter)
True

Билета нет, но приглашение есть. Одного выполненного условия достаточно, поэтому результат — True.

Разберём выражение из задач

b = 10
c = 15
a = b == 10 and c >= 12
print(a)

Python вычисляет выражения справа налево по смыслу:

  1. b == 10 — проверка: b равно 10? Результат True.
  2. c >= 12 — проверка: c больше или равно 12? Результат True.
  3. True and True даёт True.
  4. Итоговое значение сохраняется в переменную a.
Важно: в записи a = b == 10 and c >= 12 переменная a получает результат всего логического выражения. В ней будет храниться True или False.

Как работает and и or: таблица

and — И

True and True → True
True and False → False
False and True → False
False and False → False

or — ИЛИ

True or True → True
True or False → True
False or True → True
False or False → False

Интерактивный разбор условий

Измени числа и выбери оператор. Посмотри, какое значение окажется в переменной a.

Ещё один пример с or

points = 75
bonus = 0
passed = points >= 80 or bonus >= 5
print(passed)
False

Баллов меньше 80, бонус меньше 5. Ни одно из условий не выполнено, поэтому passed равно False.

Полезные операторы сравнения

  • == — равно;
  • != — не равно;
  • > — больше;
  • < — меньше;
  • >= — больше или равно;
  • <= — меньше или равно.
Частая ошибка: запись a = b = 10 не означает проверку. Для сравнения используй два знака: b == 10.
